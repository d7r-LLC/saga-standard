Monorepo Integration

How saga-app fits into the existing monorepo
saga-standard/
├── packages/
│   ├── saga-app/           # NEW — React Native iOS/Android app
│   │   └── depends on ↓
│   ├── saga-client-rt/     # Relay + messaging SDK
│   ├── saga-client/        # REST API + chain client (renamed from client)
│   ├── saga-sdk/           # Document validation + encryption (renamed from sdk)
│   ├── saga-crypto/        # Key management + envelope encryption
│   ├── contracts/          # Solidity + ABIs + TS bindings
│   ├── directory/          # STAYS — Next.js web + Electron
│   ├── server/             # Cloudflare Workers hub
│   └── cli/                # CLI tool
│
│  saga-app consumes:
│    @d7r/saga-client-rt  → messaging, relay, memory sync
│    @d7r/saga-client     → REST API, chain ops, auth
│    @d7r/saga-sdk        → document assembly, validation
│    @d7r/saga-crypto     → key ring, envelope encryption
│    @epicdm/saga (contracts) → ABIs, types, addresses
│
│  saga-app does NOT depend on:
│    packages/server         → runs independently
│    packages/directory      → separate web client
│    packages/cli            → separate CLI client
